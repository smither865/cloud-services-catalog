# Cloud Service Catalog

This repository contains a generator for a cloud services catalog workbook with two sheets:

- Service Naming Matrix
- Unique Services & Features

To generate the Excel workbook locally:

1. Install dependencies:
   pip install -r requirements.txt
2. Run the script:
   python generate_cloud_service_catalog.py

The script creates:
- cloud_service_catalog.xlsx
- cloud_service_catalog_matrix.csv
- cloud_service_catalog_unique_features.csv
